# Agenda de contactos

Proyecto de práctica de Git 

## ¿Cómo usar? 
Este repositorio contiene una pequeña agenda personal de consola organizada mediante archivos .txt. A continuación se explica la función de cada uno de ellos:

* **`README.md`**: El archivo que estas leyendo en este momento. Documento principal del repositorio que describe de qué trata el proyecto y cómo utilizarlo.

* **`contactos.txt`**: Archivo de texto que almacena la lista de contactos personales, registrando nombres, números de teléfono y correos electrónicos.

* **`tareas.txt`**: Lista de tareas pendientes y pendientes académicos por realizar.

* **`compras.txt`**: Lista de productos y víveres para el hogar (como arroz, fideos y leche).

* **`.gitignore`**: Archivo de configuración que indica a Git qué archivos y carpetas ignorar (como ser registros temporales, contraseñas, información sensible o configuraciones de editores) para evitar subirlos por error al servidor remoto.
